# Cyber Threat Detection System
A desktop-based security tool built to detect malware, 
suspicious applications, and potentially harmful open IP 
addresses on Android-connected devices. Developed during 
a 6-month cybersecurity training program at TechLive, Chandigarh.

## What It Does
- Scans connected Android devices for suspicious apps and files
- Analyses open IP addresses
- Generates a risk score based on detected threats
- Produces a detailed log file of all device activity, 
  installed apps, and browser history
- Provides a secure login system with OTP-based authentication

## My Contributions
- Designed the complete system workflow and logic architecture
- Built the login window and OTP authentication system using Tkinter
- Researched and evaluated Python libraries suitable for 
  device scanning and network analysis
- Conducted testing cycles and identified areas for optimization
- Assisted with backend logic and tool integration

## How to Run
1. Clone this repository
   git clone https://github.com/yourusername/cyber-threat-detection

2. Install dependencies
   pip install -r requirements.txt

3. Run the application
   python src/main.py

> Note: Some features require Kali Linux or a Linux environment 
> with Nmap and Wireshark installed.
